# Calculus Clash

Welcome to Calculus Clash, a web application where users can debate the historical and mathematical significance of Isaac Newton versus Joseph-Louis Lagrange.

This project is a full-stack application built entirely with React for the frontend and Manifest for the backend.

## Features

- **User Authentication**: Sign up, log in, and log out functionality.
- **Argument Posting**: Authenticated users can post arguments in favor of either Newton or Lagrange.
- **Public Viewing**: All arguments are publicly visible.
- **Upvoting**: Users can upvote arguments they find compelling.
- **Ownership Control**: Users can delete their own posts.
- **Admin Panel**: A built-in admin interface (accessible at `/admin`) for managing users and arguments.

## Tech Stack

- **Backend**: Manifest (handling database, API, authentication, and policies)
- **Frontend**: React
- **Styling**: Tailwind CSS
- **Icons**: Heroicons
- **SDK**: `@mnfst/sdk` for all frontend-backend communication
